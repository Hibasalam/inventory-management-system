\# Inventory Management System



A Django-based Inventory Management System for managing products, categories, suppliers, purchases, sales, and stock levels.



\## Technologies Used



\- Python

\- Django

\- Django REST Framework

\- SQLite

\- HTML

\- CSS

\- Bootstrap

\- Git \& GitHub



\## Features



\- Product CRUD operations

\- Category management

\- Supplier management

\- Purchase / Stock In

\- Sales / Stock Out

\- Low-stock detection

\- Inventory dashboard

\- User login and logout

\- REST API for product management



\## REST API



| Method | Endpoint | Description |

|---|---|---|

| GET | `/api/products/` | Get all products |

| POST | `/api/products/` | Add a product |

| PUT | `/api/products/<id>/` | Update a product |

| DELETE | `/api/products/<id>/` | Delete a product |



\## Project Purpose



This project was developed to practice backend development using Django, database management, REST APIs, CRUD operations, and Git/GitHub.
